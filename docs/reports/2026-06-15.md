## Technical Learnings

- Resend's `"to"` field accepts a JSON array natively — no API changes needed to send to multiple recipients
- `@Value("${SENDER_EMAIL:${spring.mail.username:}}")` syntax allows nested Spring property fallback chains
- Resend's sandbox `onboarding@resend.dev` restricts delivery to the account owner only — domain verification is required for external recipient delivery
